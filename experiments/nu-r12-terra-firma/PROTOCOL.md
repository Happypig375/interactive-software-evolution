## Fixed observations and sequence

Assign L0 (original scene), followed by L1 (fresh process reopening L0's saved
Scene.nugroup) if L0 produces a complete parseable save and both observations.
Use separate private application copies and the same compiled observer, assets,
host and configuration. L1 changes only the scene bytes to L0's exact save;
retain a separate original scene for a fixed name/fixture correspondence.
Do not require favorable L0 predicates before L1: an adverse complete save is
still eligible. A missing save or incomplete native process leaves L1 unrun.

Count external preProcess callbacks. At the first external postProcess where
Scene exists, capture A regardless of expected counts, values or family state.
At the immediately following external postProcess, capture B, save the group
once with World.writeGroupToFile, and exit normally. There is one intervening
rendering opportunity; neither framebuffer completion nor native-state
restoration is asserted. Do not wait for a success-filtered state. Use at most
120 callbacks and a 180-second process deadline; retain the phase reached,
exceptions, stderr, cleanup result and all partial observations.
At A require GameState=Gameplay and the Gameplay screen selected. Record a
failed state precondition at this first Scene-exists observation; do not delay
A until those predicates become favorable. Save to a distinct new writable
private path, never over the read-only published input. Parse the saved file as
GroupDescriptor and compare its canonical descriptor with the in-memory
writeGroup descriptor at B. Keep any mismatch as an adverse save result.

Each capture records world mode/advancing/time, original names and dispatcher
types, live hierarchy including generated entities, persistent/protection
flags, entity IDs, all original explicit properties obtainable through public
getters, links and complete saved PropagatedDescriptorOpt symbols. Also obtain
the selected properties below even when absent/defaulted in the source.
Preserve full Nu-written group descriptors privately. Parse only descriptor
child lists for entity counting; never count nested saved history as live.
Record omitted properties, conversion errors and missing names explicitly.

The fixed original correspondence is all 197 names/parents/dispatchers. All
166 explicit links must still resolve to their declared sources. The saved
history on each of the 11 source addresses must equal the original descriptor
symbol after structural parsing/canonical map serialization; no conversion of
old material records to new records is allowed inside that comparison.

For the four Villas and 32 palms, record Position, PositionLocal, Rotation,
RotationLocal, Scale, ScaleLocal, Size, Offset, MountOpt, Static, BodyShape,
StaticModel, Clipped and MaterialProperties where applicable. Compare original
explicit transform/configuration values with L0 actual values; properties
omitted from the original provide observed baselines, not invented expected
defaults. Compare L0 B against L1 A and B for these selected observed fields,
all original identities/parents/dispatchers, links and saved source history.
For Position, PositionLocal, Rotation, RotationLocal, Scale and ScaleLocal
only use absolute component tolerance 0.0001; require finite values.
Size and Offset require structural equality, as do other configuration,

ambiguity in the earlier phrase "numeric transform components"; no application

Record observed persistence/protection and child membership as well. Preserve
the generated application runtimeconfig, effective GCSettings.IsServerGC,
world flags, window flags and viewports separately from requested settings;
App.config does not prove effective GC or TieredPGO behavior.
The checker requires a contiguous post-process phase record from callback 1
through B and identifies A as the earliest Scene-exists callback. Retain and
verify all pre-existing application bytes and attributes after each run;
record new files separately. Bind comparison inputs to the accepted build,
protocol, raw process result, summary and full observation manifest.

Capture A-to-B changes and every other explicit-property mismatch as
descriptive evidence. In particular halted execution does not guarantee that
character LastTimeGrounded or other runtime properties remain unchanged.
Generated character visuals and UI children are reported separately from the

## Disposition and acceptance

Wrong input/host/source, missing required observations, observer/conversion
failure that prevents the declared comparison, an exception, failed cleanup or
a deadline is invalid/incomplete feasibility. A complete correctly observed
load/save/reopen that changes a declared configuration, link, history or named
correspondence is valid adverse evidence. Preserve all mismatches and both
assigned attempts; do not change the fixture to obtain a favorable result.
An additional diagnostic or correction needs a prospective label and must
retain the original. Five unresolved failures at one unchanged construction
gate trigger return. Independent source/harness review and parent acceptance,
then compiled-source/host verification, precede native application execution.

A passed pair establishes only this configuration/history correspondence for
this adapted native application and phase. It does not establish propagation
under tint/roughness changes, source deletion behavior, native object/contact
identity, visual rendering, interaction replay, physics continuation, Gaia
editing access, practical task demand, authoring effort or comparative benefit.
