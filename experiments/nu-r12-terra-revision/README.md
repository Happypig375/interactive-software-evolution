# Terra Firma material revision comparison

Construction package for the accepted [prospective protocol](PROTOCOL.md).
No native revision result is established by this package yet. It extends the
[published load/save/reopen prerequisite](../../docs/nu-terra-firma-reopen-feasibility-2026-10-18.md)
with a shared palm tint and an independent local roughness requirement.

`Program.fs` compiles alongside the same eight unchanged Terra Firma units.
It observes the fixed phases, applies one public propagation or one field-wise
batch operation, saves the actual endpoint, and records public lifecycle
callbacks through cleanup. `run.py` composes the hash-pinned prerequisite
runner for source/assets/host staging, process deadlines and compiled-source
acceptance. The maintainer enforces the fixed case/reopen chronology in the
private attempt ledger. It is not a candidate agent workflow.

`oracle.py` and `compare.py` score declared configuration, saved histories,
actual-predecessor reconstruction and callback-stream integrity separately.
`check_controls.py` constructs explicitly synthetic records from the retained
prerequisite to falsify checker behavior. Its invented receipts and outcomes
are never experimental evidence. All control inputs and failures are retained
privately; no copyrighted scene or extraction is included in Git.
