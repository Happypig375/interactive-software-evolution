# Nu value research

This project investigates where Nu's approach to state, domain modeling, coordination and development tools provides useful differences, and what evidence would establish their value. **Interactive Software Evolution (ISE)** remains the repository's internal codename.

Start with [PLAN.md](PLAN.md) for the current assignment and authority. The active work is the whole-background literature survey; experimental construction and live allocation remain on hold. Positive, null and adverse evidence all belong in the assessment. Nu-specific benefits and priority remain unconfirmed.
