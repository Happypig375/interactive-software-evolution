## Practical question and comparison

The [existing Terra Firma family](nu-reuse-and-authoring-contract-2026-10-11.md#2026-10-18-existing-terra-firma-family-and-next-revision-case)
contains 32 palms across four Villas, 197 actual serialized entities, 166
explicit propagation links and 11 saved source histories. The proposed shared
tint/local roughness task is authored; the existing asset is its provenance,
not evidence of a requested task's prevalence or demand.

Before comparing that revision with an ordinary batch helper, this feasibility
asks whether the unchanged application loads the family configuration and
retains it through ordinary group save and fresh-process reopen. The observer
uses the original eight application units and TerraFirmaPlugin, a separately
reviewed Program, and public World.runPlus callbacks. Original custom
dispatchers, native initialization and assets remain present. The prior
Button/Text stub-world propagation result cannot answer this question.

L0 is assigned the original scene; eligible L1 reopens L0's actual saved bytes
in a fresh application copy, including an adverse completed predecessor. A is
the first post-process where Scene exists; B is the immediately following
post-process. The checker uses all preceding phase records to enforce that
choice. It distinguishes the 197 original entities from generated character
visuals and UI, compares each link/history at its original source address,
and observes the four Villas and 32 palms. Position/rotation/scale use the
prospective 0.0001 component tolerance; Size/Offset and other configuration
use structural equality. Halted execution can still alter runtime fields.
