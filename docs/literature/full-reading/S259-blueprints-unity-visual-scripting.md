## Qualitative mechanism, counterevidence and Nu consequence

The shared BP themes support rapid iteration, perceived safety, gameplay/UI work and collaboration through code-exposed parameters. They also explicitly report harder testing, modularization and merging, growing graph disorder, and a preference for C++ in core architecture, performance and reusable large systems. Suggested hybrid percentages are opinions, not measured optimal allocations.

The Unity portion reports node-search/selection burdens, lengthy mathematical graphs, translation from familiar C# concepts, unfamiliar hierarchy, disappointing documentation and errors that users found hard to trace from console messages to graphs. It also supports **C# plus UVS orchestration**, high-level touchpoints for non-programmers, and possible advantages for state machines/audio or less mathematical tasks. Preserve these conditional positives alongside adverse movement-task experience. The study contains no randomized abstraction/debugger intervention, production adoption sample or comparative maintenance-cost observation. Participant reports about generated code, debugger behavior and crashes are not independent version-specific API or safety verification.

For Nu, the useful mechanism questions are whether domain operations, state inspection, error location and a usable code/model boundary reduce actual work while retaining developer control, and what testing, merging and runtime costs they introduce. This evidence makes integration and task fit consequential; it does not identify visual notation, immutable state, types, MMCC or ImSim as the cause of benefit. S258's localization counterweight remains relevant. A location highlight or connected graph still does not demonstrate that semantic and temporal obligations were checked.

The next consequential route is the **2024 Unreal energy/task predecessor**, to connect development experience with runtime cost and task lineage. Version-specific diagnostic documentation remains a separate mechanism-verification gap. Modern practice, Phylogenix, generative-asset integration, postmortem continuation and temporal/state alternatives remain open; another search page cannot determine Nu's empirical benefit.
